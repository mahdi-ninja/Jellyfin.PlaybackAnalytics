# Changelog

## 1.0.0.0

- Initial Jellyfin 12 release.
- Complete playable-media report including never-watched items.
- Storage size, total viewing hours, sessions, latest viewer and all viewers.
- Series aggregation with watched/unwatched episode counts and completion percentage.
- Search, filtering and sortable columns.
- CSV export for both item and series views.
- No direct access to Jellyfin's library database or Playback Reporting SQLite file.
